# معمل الفيزياء الافتراضي — الإصدار 4

معمل فيزياء ثلاثي الأبعاد للصف الأول (الفصل الأول: الفيزياء والقياس والحركة)، من إعداد **مستر محمد محمود** — مدرس الفيزياء بمركز التدريب، شركة ترسانة الإسكندرية.

- عشر محطات تجارب تفاعلية، وخريطة رحلة زي الألعاب، وشارات ونقاط.
- شرح صوتي للمعلم بصوتين تختار بينهم: **كريم** (فصحى، موجود جاهز) و**شاكر** (مصري طبيعي، بيتعمل تلقائياً على GitHub).
- اختبار نهائي من بنك 172 سؤال، وشهادة قابلة للطباعة.
- أكتر من طالب على نفس الجهاز، ولوحة معلم بتنزّل النتائج Excel.
- **تطبيق على الموبايل (PWA):** بيتثبّت على الشاشة الرئيسية وبيشتغل من غير نت بعد أول فتح.

---

## التشغيل على الكمبيوتر من غير نت
دبل كليك على `RUN.bat` (ويندوز)، أو افتح `index.html` في Chrome أو Edge.

## الرفع على GitHub عشان يبقى ليه لينك على الموبايل

### 1) اعمل مستودع جديد
من github.com اضغط **New repository**، سمّيه مثلاً `physics-lab`، وخليه **Public**.

### 2) ارفع الملفات
**الأسهل: GitHub Desktop**
1. نزّل GitHub Desktop وسجّل دخول.
2. File ← Clone repository ← اختار `physics-lab`.
3. انسخ **كل محتويات** فولدر `PhysicsLab_v4` جوه فولدر المستودع (بما فيها فولدر `.github` المخفي).
4. اكتب أي وصف واضغط **Commit to main** ثم **Push origin**.

**أو من المتصفح:** Add file ← Upload files، واسحب الملفات. المتصفح بيقبل 100 ملف في المرة، فارفع فولدر `voice` لوحده في مرة، وباقي الملفات في مرة تانية. اتأكد إن فولدر `.github` اترفع.

### 3) شغّل GitHub Pages
Settings ← Pages ← في **Source** اختار **GitHub Actions**.

### 4) استنى دقيقتين
من تبويب **Actions** هتلاقي «نشر المعمل على GitHub Pages» شغال. أول مرة بيولّد صوت شاكر (حوالي دقيقة)، وبعدها اللينك بيظهر:

```
https://اسم-حسابك.github.io/physics-lab/
```

### 5) على الموبايل
افتح اللينك، وبعدين:
- **أندرويد (Chrome):** هيظهر زر «ثبّت المعمل»، أو من القائمة ⋮ ← «إضافة إلى الشاشة الرئيسية».
- **آيفون (Safari):** زر المشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية».

بعد أول فتح، المعمل والصوت بيتحفظوا على الموبايل ويشتغلوا من غير نت.

## صوت شاكر
- بيتعمل **تلقائياً** على GitHub أول مرة، وبيتحفظ في المستودع في `voice/shakir`.
- عايزه على الكمبيوتر من غير GitHub؟ شغّل `tools\Make-Shakir-Voice.bat` وانت متوصل بالنت (محتاج Python).
- الطالب بيختار الصوت من: لوحة الطالب ← الإعدادات ← صوت المستر.

## تعديل كلام المعلم
الجمل في `tools/lines.json`: `say` هو النص المنطوق (مُشكَّل)، و`text` اللي بيظهر مكتوب. لو غيّرت جملة، امسح ملفها من `voice/shakir` وارفع تاني، وهتتولّد من جديد.

## محتويات الفولدر
| المسار | إيه هو |
|---|---|
| `index.html` | المعمل |
| `assets/` | التصميم والكود والخطوط والصور وبنك الأسئلة |
| `voice/kareem/` | صوت كريم (جاهز) |
| `voice/shakir/` | صوت شاكر (بيتولّد تلقائياً) |
| `sw.js` و`manifest.webmanifest` و`icons/` | تطبيق الموبايل والعمل بدون نت |
| `tools/` | سكريبت توليد صوت شاكر |
| `.github/workflows/deploy.yml` | النشر التلقائي على GitHub Pages |
